# Gestion des Étudiants - PHP/MySQL

## Installation
1. Clonez ce dépôt dans votre dossier `htdocs`.
2. Importez le fichier `database.sql` dans votre serveur MySQL (via phpMyAdmin).
3. Assurez-vous que les identifiants dans `config.php` correspondent à votre configuration locale.
4. Créez un dossier nommé `uploads` à la racine du projet s'il n'existe pas.
